Политика конфиденциальности Dev Trainer

Дата последнего обновления: 10 ноября 2026.

Dev Trainer — приложение для подготовки к техническим собеседованиям и тренировки английского. Обучение, прогресс и настройки работают офлайн. Приложение не собирает данные автоматически и не передаёт прогресс обучения куда-либо. Единственное, что может покинуть устройство, — письмо, которое вы отправите сами из «Обратной связи» (см. ниже).

Какие данные не собираются автоматически

  • имя, фамилия, адрес электронной почты, номер телефона;
  • аккаунты и пароли: регистрации и входа в приложение нет;
  • геолокация, контакты, камера, микрофон, файлы устройства;
  • рекламные идентификаторы и любые идентификаторы для отслеживания;
  • статистика использования, отчёты о падениях, аналитика поведения.

В приложении нет рекламных и сторонних аналитических SDK, встроенных социальных сетей и форм, которые отправляют данные без вашего участия.

Что хранится только на устройстве

Прогресс обучения (ответы на вопросы, серия дней, точность, избранное, повторения слов, заметки к вопросам), настройки (цели на день, выбранные уровни и темы, колоды, время напоминания, размер шрифта) и отметка о добровольной поддержке хранятся в приватном хранилище приложения на телефоне. Эти данные не отправляются на серверы и не передаются третьим лицам; они покидают устройство только в резервной копии, которую пользователь сохраняет сам. Системная резервная копия Android и перенос данных на новое устройство для приложения отключены.

Обратная связь

В настройках есть кнопки «Сообщить о проблеме» и «Предложить улучшение». Они ничего не отправляют автоматически: открывается ваша почтовая программа с черновиком письма. В черновик подставляются версия приложения, модель устройства, версия Android, язык, тема оформления, размер экрана и журнал работы приложения. Письмо уходит только после того, как вы сами нажмёте «Отправить», и только на адрес разработчика из раздела «Контакты». Вместе с письмом разработчик получает адрес отправителя и перечисленные технические данные; они используются только для ответа и исправления ошибки.

Разрешения

  • Уведомления (Android 13 и новее) — для ежедневного напоминания, если пользователь включил его в

настройках.

  • Запуск после перезагрузки — чтобы напоминание продолжало работать.
  • Доступ в интернет и состояние сети — используются только для связи с RuStore: при запуске

приложение проверяет, не куплена ли поддержка раньше, и для самой оплаты. Обучение полностью работает без интернета.

  • Служебные разрешения планировщика задач (wakelock и запуск задач в фоне) — только для доставки

напоминания в выбранное время.

Камеру, микрофон, геолокацию, контакты и доступ к файлам приложение не запрашивает.

Резервная копия

Пользователь может сохранить прогресс в JSON-файл. Файл создаётся по команде пользователя и сохраняется в выбранное им место через системный выбор файла. Приложение не загружает копию в сеть и не имеет доступа к другим файлам устройства.

Добровольная поддержка

Приложение бесплатное. Одноразовая покупка «Поддержать проект» (300 ₽) необязательна и не открывает дополнительный контент. Платёж проводит RuStore: приложение получает только факт покупки и её время, но не данные банковской карты. В составе RuStore Pay SDK есть служебные модули (метрики и идентификатор установки), необходимые для работы платежей; обработка платежа и связанных с ним данных регулируется документами RuStore.

Хранение и удаление

  • Прогресс, настройки и заметки хранятся на телефоне, пока установлено приложение.
  • Сбросить прогресс можно в приложении: «Настройки → Сбросить прогресс по вопросам» и

«Сбросить прогресс по English».

  • Полное удаление — удаление приложения с устройства; серверных копий прогресса у приложения нет.
  • Письма обратной связи хранятся до завершения обращения и не более 12 месяцев, затем удаляются.

Попросить удалить письмо раньше можно на контактный адрес.

Дети

Приложение не предназначено для детей: содержание рассчитано на взрослых, готовящихся к техническим собеседованиям. Данные пользователей любого возраста автоматически не собираются, рекламы нет.

Изменения политики

Актуальная версия политики всегда доступна в приложении: «Настройки → Политика конфиденциальности». При изменении текста обновляется дата в начале документа.
